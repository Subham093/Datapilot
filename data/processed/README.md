# data/processed/

Intentionally empty. This folder exists as a local scratch
space for cleaned-dataset output — but the app's "Download
Cleaned Dataset CSV" button in the Data Quality tab streams the
result straight to your browser rather than writing it to disk
on the server, so nothing lands here during normal use.

Any `.csv` written here is gitignored (see `.gitignore`); only
the `.gitkeep` placeholder is tracked, so the folder itself
still exists in a fresh clone of the repo.

**Paste this at:** `data/processed/README.md`
